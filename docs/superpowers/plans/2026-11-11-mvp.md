# Implementación del MVP EntrePista

Web móvil para una discoteca y una barra. React con Vite para la carta y el panel, Express para la API y SQLite local para que la demo arranque sin un servicio adicional.

1. Persistir catálogo, clientes, sesiones y pedidos. Probar invitado, descuento del 5 % desde el servidor, pagos simulados y transiciones atómicas de barra.
2. Integrar Telegram por enlace de inicio y WhatsApp Cloud API por plantilla con consentimiento. Probar vinculación de un solo uso, envío al marcar listo y ausencia de duplicados.
3. Agregar Checkout Pro en modo de prueba. Validar el webhook, consultar la orden remota y comprobar monto, moneda, referencia y estado antes de preparar.
4. Implementar carta, carrito, cuenta opcional, seguimiento y panel de barra. Probar el recorrido de punta a punta a tamaño de celular.
