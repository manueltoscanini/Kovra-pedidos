# Videos de marca

La portada y cada página de rubro reutilizan el mismo MP4. El nombre del archivo debe coincidir con el de su rubro.

- `restaurantes-y-cafeterias.mp4`
- `discotecas-y-bares.mp4`
- `eventos-y-festivales.mp4`
- `hoteles-y-alojamiento.mp4`
- `clubes-deportivos.mp4`

Usá video H.264 sin audio y un fotograma WebP con el mismo nombre para la vista previa. La portada reproduce en bucle continuo el rubro seleccionado sin controles de pausa. Si falta un MP4, se muestra una imagen.

`nuestra-mision.mp4` muestra el movimiento de entrega del plato sincronizado con el desplazamiento vertical (scroll al bajar y subir) y `nuestra-mision.webp` es su vista previa. «Qué hacemos» trae una animación integrada en bucle y admite un video opcional `que-hacemos.mp4`.

Ejecutá `npm run build` después de cambiar los archivos.
